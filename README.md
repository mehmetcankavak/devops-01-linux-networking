# DevOps Modül 1 — Linux & Networking

Bu repo, DevOps yol haritamın ilk modülü olan **Linux & Networking**'i öğrenirken tuttuğum
notları, laboratuvar çalışmalarını ve çözdüğüm kriz senaryolarını belgeliyor. Amaç komut
ezberlemek değil, Linux kernel'inin arka planda nasıl çalıştığını anlamak.

## Öğrenilen Konular
- [x] Dosya Sistemi & Yetkilendirme (inode, izin bitleri, SUID/SGID/Sticky, ACL)
- [ ] Process & Kaynak Yönetimi (fork/exec, systemd, cgroups, signals)
- [ ] Ağ & Network Yönetimi (TCP/IP, routing, DNS, netfilter, SSH tünelleme)
- [ ] Storage & Disk Yönetimi (LVM, inode tükenmesi, swap)
- [ ] Log Yönetimi & Sorun Giderme (journald, logrotate, log analizi)
- [ ] Bash Scripting ile Otomasyon (strict mode, trap, idempotency)
- [ ] Capstone: Self-Healing Web Sunucusu

## Lab Ortamı
Multipass ile Ubuntu 26.04 VM (`devops-tutorial`) üzerinde çalışılıyor.
